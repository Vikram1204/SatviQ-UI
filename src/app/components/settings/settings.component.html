Sign in with Google to enable automatic cloud backups and multi-device sync via Google Drive.

⚠️ Action Needed:
Google requires a valid OAuth Client ID from your Google Cloud Console to log in.
How to get a free Google Client ID:
  1. Go to Google Cloud Console.
  2. Create a project & go to APIs & Services > Credentials.
  3. Click Create Credentials > OAuth Client ID.
  4. Add {{ redirectUriDisplay }} under both Authorized Javascript origins & Authorized redirect URIs.
  5. Enable Google Drive API in Library.
  6. Under OAuth consent screen > Test users, add your Google email address (or click Publish App).
  7. Copy the Client ID and paste it above!
